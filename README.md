# LocalPulseHub rebrand preview

A standalone preview of the localpulsehub.com landing page in the new brand: navy and lime, Anton and Archivo, and the pulse line.

- `index.html` is the whole page. It has no build step, so you can open it in a browser.
- `fonts/` holds the self-hosted Anton and Archivo files (SIL Open Font License, licenses included).

The copy and SEO title and description come from the live site. Buttons link to the real pages on localpulsehub.com.
